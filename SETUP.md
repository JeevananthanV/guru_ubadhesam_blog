# Guru Ubadhesam Blog — Setup Guide

Welcome to the **Guru Ubadhesam Blog** setup guide. This spiritual discourse and wisdom teachings web application is built with React 18 and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/guru_ubadhesam_blog](https://github.com/JeevananthanV/guru_ubadhesam_blog)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/guru_ubadhesam_blog.git
cd guru_ubadhesam_blog
```

---

## 📦 2. Install Dependencies & Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build

```bash
npm run build
npm run preview
```
Output files are generated in `dist/`.
